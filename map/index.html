    ใส่ TomTom API key

    ใช้สำหรับจราจรสดและธีมมืด แผนที่ 3D ธีมสว่างใช้ได้โดยไม่ต้องมี key

    1. เปิดเว็บ developer.tomtom.com แล้วกด Register / Sign up
    2. กรอกอีเมลกับรหัสผ่าน แล้วกดลิงก์ยืนยันในอีเมล
    3. ล็อกอิน เข้าเมนู API Keys แล้วกดคัดลอก key
    4. กลับมาหน้านี้ วาง key ด้านล่าง แล้วกดบันทึก
